# Wiktionary translation index

This index is derived from [Multilingualism](https://github.com/MethodoxTech/Multilingualism/tree/fe427837f392a90f8d68a3e69c7c9f3c1f716bb9), revision `fe427837f392a90f8d68a3e69c7c9f3c1f716bb9`, data version `2026-10-22`. Attribution: **Multilingualism, from Wiktionary contributors**. The source data is licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); Wiktionary content is also available under the GFDL.

The generated file contains **519,230 non-machine-flagged translation pairs** across **108 language categories**, from **9,852 English headwords**. All **544,786 machine-flagged rows** were excluded. These are translation-table equivalents, not full definitions, distinct word counts, or comprehensive coverage. Each result links to the original English Wiktionary entry, whose page history credits contributors.

To rebuild, obtain the pinned repository's `data` directory with `meta.json`, `index.json`, and `langs/<code>.json`, then run:

```sh
npx tsx scripts/build-multilingual-index.ts /path/to/Multilingualism/data
```

The builder validates the source schema and machine flags, sorts normalized terms, and generates both the gzip index and `manifest.json`. Retain attribution and share-alike terms when redistributing.
